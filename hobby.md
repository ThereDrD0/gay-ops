# Мой пет-проект

Идея: Telegram-бот для учёта личных расходов и просмотра статистики по категориям.

Стек: Python, aiogram, SQLite.
Цель: научиться разрабатывать небольшое приложение с обработкой команд, хранением данных и базовой аналитикой.

Срок реализации: 2 недели.
Минимальные команды бота: `/start`, `/add`, `/summary`.
